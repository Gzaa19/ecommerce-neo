## Processing and reuse

EXIF orientation normalized, resized proportionally to maximum 1000 px per side without upscaling, converted to RGB and compressed as WebP (quality 84). No generated products, background removal, object replacement, or intentional crop. Some framing/cropping is already present in source photographs. CC BY-SA adaptations remain under the corresponding CC BY-SA license listed below; this does not relicense unrelated application code. Public-domain status is the status reported by each Commons file record; no invented license URL is assigned where API metadata has none. Any of these assets may also illustrate the demo hero, retaining its attribution and demo status.

License/author evidence retrieved from Wikimedia Commons `imageinfo.extmetadata`, not inferred from search snippets. Exact metadata query URL recorded per asset below.
